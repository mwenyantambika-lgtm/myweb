# Mwenya Ntambika | Interactive Personal Website

ICT251 Web Technologies, Activity 3, Mulungushi University.

An interactive student portfolio built with plain HTML5, CSS and JavaScript. It includes About Me, Hobbies, Learning Plan, Projects and Skills, Photos, Media (video and audio) and a Contact form.

## The four JavaScript features

1. *Contact form validation and preview*: checks name, email and message. It rejects empty or spaces-only text and badly formatted emails, and shows a local preview without reloading. Nothing is sent anywhere.
2. *Theme switch*: toggles between light and dark mode.
3. *Mobile navigation*: a Menu button opens and closes the links on narrow screens.
4. *Gallery viewer*: Previous and Next buttons change the photo and its caption, and the buttons are disabled on the first and last photo.

## How to test

- *Form:* submit it empty, then with spaces only, then with an email like abc. Each should show an error. Then enter valid details to see the preview.
- *Theme:* click Dark mode, scroll through the page, then click Light mode.
- *Menu:* narrow the browser to about 375px and tap Menu, then tap a link.
- *Gallery:* click Next to the last photo and Previous back to the first.
